# Contributing

Simorg Desktop is written in Simorg's own repository and published here with
each release, so **this repository takes no pull requests**: a change merged
here would be replaced by the next release.

- **A bug, or something missing?** [Open an issue](https://github.com/simorg-platform/simorg-desktop/issues).
  Say what you did, what you expected and what happened, with your operating
  system and the version from **Settings → Updates**.
- **A vulnerability?** Privately, never in an issue — see [SECURITY.md](SECURITY.md).
- **Building it yourself?** [Building from source](README.md#building-from-source),
  then [docs/packaging.md](docs/packaging.md) for archives that run anywhere.
