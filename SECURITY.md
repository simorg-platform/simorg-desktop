# Security

**Report a vulnerability privately, never in an issue.** An issue is public the
moment it is opened, long before there is a fix.

Open this repository's
[security advisories](https://github.com/simorg-platform/simorg-desktop/security/advisories)
and press **Report a vulnerability**. Only you and Simorg can read the report,
and the conversation about it stays in that same private thread.

## What to report here

Anything in Simorg Desktop. A problem you find through it in the Simorg
machine service or the platform belongs here too: we take it to the part that
has to change.

## Which versions are fixed

The newest release. A fix ships as a new version, and every installed copy is
offered it in **Settings → Updates** — so an older version is fixed by updating,
not by a patch of its own.
